# 新增专区效果图

静态画面，用来看新增专区的完整流程。还没有改应用功能。图里的模板标题和正文是演示数据。

窗口为 1280×1080。侧栏把原来的「进入专区」换成专区列表：「当前界面」固定在最上，下面是各个专区，最后是「新增专区」。点某一项就进入它的模块导航。新专区先是空白，模块在设置里分配。现有的「专区」保留，可以用铅笔改名。

| 图 | 画面 |
| --- | --- |
| [01-当前界面-专区列表.png](01-当前界面-专区列表.png) | 当前界面。侧栏列出「当前界面」「专区」和「新增专区」，模块导航仍是现在的五个模块。 |
| [02-新增专区弹窗.png](02-新增专区弹窗.png) | 新增专区。填写名称、一句说明，并选图标。创建后是空白专区。 |
| [03-空专区.png](03-空专区.png) | 刚创建的「读书」。侧栏选中它，模块导航为空，主区提示到设置里分配模块。 |
| [04-设置-专区与归属.png](04-设置-专区与归属.png) | 设置里管理专区，并把模块分到当前界面或某一个专区。示例把「核心思想」分到「读书」。铅笔是重命名，删除后该专区里的模块回到当前界面。 |
| [05-读书专区-核心思想.png](05-读书专区-核心思想.png) | 分配之后的「读书」。侧栏只出现「核心思想」。 |
| [06-删除专区确认.png](06-删除专区确认.png) | 删除「读书」前的确认。 |
